# Hyprland

GPU **AMD**, teclado **português (Portugal)**, configuração em **Lua** (Hyprland 0.55+).

### Instalar

```
git clone https://github.com/JoaoPedroPierri/dotfiles
bash dotfiles/install/arch-install.sh      # Arch Linux (live ISO)
```

Depois do primeiro arranque (dentro do Hyprland):

```
~/.joao-repo/dotfiles/hyprland-install
```

Ver o [guia completo](archlinux-install.md).
